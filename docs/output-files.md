# Output Files

aidocs generates four types of files optimized for LLM consumption.

## llms.txt

The root navigation file placed at project root. Provides AI agents with:
- Project name and description
- Links to manifest and full index
- Quick document overview

Example:
```markdown
# My Project

> Project description

## For AI Agents
- Pattern Manifest: /docs/_ai/manifest.json
- Full Index: /docs/llms-full.txt

## Documentation
- [Getting Started](docs/getting-started.md): Quick setup guide
- [API Reference](docs/api.md): Complete API docs
```

## llms-full.txt

Complete document index with full metadata. Organized by section:

```markdown
# My Project - Complete Document Index

Total Documents: 10

## Guide

### Getting Started
Path: docs/getting-started.md
Description: Quick setup guide
Tags: quickstart, setup
Tokens: 400

## Reference

### API Reference
Path: docs/api.md
Description: Complete API documentation
Tags: api, reference
```

## manifest.json

Structured metadata for programmatic access:

```json
{
  "knowledgeBase": {
    "name": "My Project",
    "generatedBy": "aidocs",
    "optimizedFor": ["Claude Code", "AI Agents"]
  },
  "documents": [
    {
      "id": "getting-started",
      "name": "Getting Started",
      "description": "Quick setup guide",
      "section": "guide",
      "tags": ["quickstart", "setup"],
      "estimatedTokens": 400
    }
  ],
  "sections": {
    "guide": {
      "count": 1,
      "documents": ["getting-started"]
    }
  },
  "metadata": {
    "totalDocuments": 10,
    "averageTokensPerDoc": 450
  }
}
```

## tags.json

Aggregated tag index for tag-based discovery:

```json
{
  "tags": {
    "encryption": {
      "count": 3,
      "documents": ["blind-records", "blind-keys", "example-keys"]
    },
    "example": {
      "count": 2,
      "documents": ["example-record", "example-keys"]
    }
  },
  "totalTags": 15,
  "topTags": ["encryption", "records", "keys", "example", "storage"]
}
```

Fields:
- `tags`: Map of tag name to documents containing that tag
- `totalTags`: Total number of unique tags
- `topTags`: Top 10 most common tags (sorted by count, then alphabetically)

## Cache File

`.cache.json` stores content hashes and AI-generated summaries to avoid redundant processing.
