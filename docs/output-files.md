# Output Files

aidocs generates three types of files optimized for LLM consumption.

## llms.txt

The root navigation file placed at project root. Provides AI agents with:
- Project name and description
- Links to manifest and full index
- Quick document overview

Example:
```markdown
# My Project

> Project description

## For AI Agents
- Pattern Manifest: /docs/ai-optimization/manifest.json
- Full Index: /docs/llms-full.txt

## Documentation
- [Getting Started](docs/getting-started.md): Quick setup guide
- [API Reference](docs/api.md): Complete API docs
```

## llms-full.txt

Complete document index with full metadata. Organized by category:

```markdown
# My Project - Complete Document Index

Version: v1.0.0
Total Documents: 10

## Guide

### Getting Started
Path: docs/getting-started.md
Description: Quick setup guide
Tags: quickstart, setup
Tokens: 400

## Reference

### API Reference
Path: docs/api.md
Description: Complete API documentation
Tags: api, reference
```

## manifest.json

Structured metadata for programmatic access:

```json
{
  "knowledgeBase": {
    "name": "My Project",
    "version": "v1.0.0",
    "generatedBy": "aidocs",
    "optimizedFor": ["Claude Code", "AI Agents"]
  },
  "patterns": [
    {
      "id": "getting-started",
      "name": "Getting Started",
      "description": "Quick setup guide",
      "category": "guide",
      "tags": ["quickstart", "setup"],
      "estimatedTokens": 400
    }
  ],
  "categories": {
    "guide": {
      "count": 1,
      "documents": ["getting-started"]
    }
  },
  "metadata": {
    "totalDocuments": 10,
    "averageTokensPerDoc": 450
  }
}
```

## Cache File

`.cache.json` stores content hashes and AI-generated summaries to avoid redundant processing.
